## 1. Personal Portfolio V2 (Website Ini)
Website ini bukan sekadar CV statis, melainkan aplikasi *Fullstack* yang lengkap.
- **Tech Stack:** Go (Gin) di Backend, Vue 3 + Tailwind di Frontend, MySQL Database.
- **Fitur Teknis:** - **Dynamic Content:** Semua data proyek, pengalaman, dan produk dikelola via Database.
    - **Admin Dashboard:** Memiliki panel admin terproteksi JWT untuk CRUD konten tanpa koding ulang.
    - **Security:** Rate Limiter middleware, Secure Headers, Environment Variable management.
    - **Performance:** Frontend di-build dengan Vite, Backend menggunakan Go routines untuk concurrency, Image serving optimasi.
    - **Interactive UI:** Menggunakan komponen kustom seperti `PixelBlast.vue` (Three.js) dan `CardSwap.vue`.

## 2. AI Chatbot Assistant (Fitur di Website Ini)
Asisten virtual cerdas yang tertanam di portofolio untuk menjawab pertanyaan pengunjung secara real-time.
- **Metode:** Menggunakan teknik **RAG (Retrieval-Augmented Generation) Sederhana**.
- **Cara Kerja:** Backend membaca "Knowledge Base" (file markdown ini) ke dalam memori, lalu menyuntikkannya sebagai konteks ke LLM (Google Gemini Flash) saat user bertanya.
- **Keunggulan:** Respon akurat sesuai data Aldi, bukan halusinasi AI umum.
